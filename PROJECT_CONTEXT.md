# Mục tiêu dự án

Đây là web app tải video từ Internet.
Thuật toán tải video hiện đã ổn định, không được tự ý thay đổi.

# Phạm vi được phép sửa

- UI/UX
- Responsive layout
- Form nhập URL
- Trạng thái loading, progress, success, error
- Lịch sử tải
- Validation
- Accessibility
- Các lỗi frontend và API integration

# Không được làm

- Không thay đổi thuật toán tải video nếu không cần thiết
- Không xóa dữ liệu người dùng
- Không đổi framework nếu chưa được yêu cầu
- Không bỏ qua lỗi build hoặc test

# Tiêu chí hoàn thành

- Desktop và mobile đều hiển thị tốt
- Không có lỗi console nghiêm trọng
- Các nút và trạng thái đều hoạt động
- Có loading, empty state, error state và success state
- Chạy được lint, test và production build
- Tự kiểm tra bằng trình duyệt
- Tóm tắt mọi file đã thay đổi
